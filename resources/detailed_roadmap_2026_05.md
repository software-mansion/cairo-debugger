# Detailed roadmap

| Task                                                                                                     | Size | Reasoning                                                                                                                                                                    |
|----------------------------------------------------------------------------------------------------------|------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Retrieving values of function args                                                                       | 2    | Core feature - they are shown only after their first usage                                                                                                                   |
| Retrieving values of complex variables (structs, enums)                                                  | 3    | Core feature - only numeric types of size <= felt252 are supported right now                                                                                                 |
| Stop showing variables once they are not in scope                                                        | 2    | Not critical, but it's misleading when variables which are out of scope are shown                                                                                            |
| Retrieving values of variables stored in different memory segments (arrays, dicts)                       | 3    | Core feature - requires special handling due to the memory segments                                                                                                          |
| Support debugging contract calls in [snforge](https://foundry-rs.github.io/starknet-foundry/)            | 5    | Big topic, requires changes of internal debugger architecture, but easy debugging of complex contract flows would be a really big improvement to the devX of whole ecosystem |
| Integrate [`scarb execute`](https://docs.swmansion.com/scarb/docs/extensions/execute.html) with debugger | 2    | Nice to have + relatively low effort, depends on how many users would want that                                                                                              |
| Figure out how to support starknet storage                                                               | 5    | A plan for the distant future - another big topic (and huge devX improvement) to be done after supporting contract calls                                                     |
